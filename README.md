## 🏨 Triple Peaks Hotel Assistant Chatbot  
**Built with Zapier | AI Automation Project by Francois O Yengue**

### 📌 Project Overview  
This project demonstrates the creation of a fully functional hotel assistant chatbot using **Zapier’s Simple FAQ Chatbot template**. The chatbot is designed to assist guests with common inquiries such as:

- Check-in/check-out times  
- Room amenities  
- Booking modifications  
- Nearby attractions  
- General hotel services

The chatbot uses a structured knowledge base to deliver clear, professional, and conversational responses.

### ⚙️ Tools & Technologies  
- **Zapier Chatbots**  
- **Cloud Storage (Zapier Data Store)**  
- **PDF Knowledge Source**: Triple Peaks Hotel FAQ  
- **Directive Wizard**: For tone and fallback configuration

---

### 🧠 Knowledge Base  
The chatbot is powered by the **Triple Peaks Hotel Knowledge Base** (PDF), which contains frequently asked questions and service details. This document was uploaded and connected as the primary data source.

---

### 🛠️ Setup Instructions  
1. **Create a Zapier Account**  
   Sign up at [zapier.com](https://zapier.com) and access the Chatbots section.

2. **Use the Template**  
   Select the **Simple FAQ Chatbot** template.

3. **Name Your Bot**  
   Example: `Triple Peaks Hotel Assistant`

4. **Upload Knowledge Source**  
   - Go to **Knowledge Sources**  
   - Upload the provided hotel FAQ PDF  
   - Confirm the chatbot retrieves data from this source

5. **Connect Data Store**  
   - Create a **Cloud Storage** data store  
   - Link the uploaded PDF  
   - Wait for processing to complete

6. **Configure Tone & Fallback**  
   - Use the **Directive Wizard** to set tone: helpful, professional, concise  
   - Add a fallback message for out-of-scope questions

7. **Publish & Test**  
   - Click **Publish** to make the chatbot live  
   - Copy the public link  
   - Test with at least five user questions  
   - Capture screenshots of setup and conversations

### 💬 Example Interactions  
**User**: “What time is check-in?”

**User**: “Can I cancel my reservation?”  
**Bot**: “Yes, you can cancel up to 24 hours before check-in. Use the link in your confirmation email or contact the front desk.”

**User**: “Do you offer breakfast?”  
**Bot**: “Yes! We offer complimentary continental breakfast daily from 6:30 AM to 10:00 AM in the lobby.”
